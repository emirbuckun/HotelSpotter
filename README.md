## Run

Clone the project

```bash

git clone https://github.com/emirbuckun/HotelSpotter.git

```

Go to the client or server directory

```bash

cd client
cd server

```

Install dependencies

```bash

npm install

```

Start the server

```bash

npm run dev

```
